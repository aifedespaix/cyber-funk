# Licences des polices

dont la colonne Licence est remplie : une police sans ligne, ou marquée `À COMPLÉTER`, voit ses motifs sautés avec un
avertissement (le dépôt démarre quand même). Le nom d'une police est celui de son fichier, sans extension.

## Écart à lever par l'utilisateur

Les polices graffiti ci-dessus sont déclarées CC0 par l'utilisateur, mais les fichiers de licence DANS les archives
disent autre chose :

- `jraot.zip` (`Read Me.txt`) : version démo, usage personnel uniquement, licence commerciale à acheter ;
- `street_wars.zip` (`Read Me.txt`) : version démo, usage personnel uniquement, usage commercial interdit ;
- `throwupz.zip` (`License - READ THIS.txt`) : usage personnel uniquement, partage interdit sans accord du dessinateur ;
- `don_graffiti.zip` (`Read Me 2018.pdf`) : redistribution interdite.

Ces textes contredisent CC0. Si l'utilisateur détient une licence plus large (page de téléchargement, achat), il doit
