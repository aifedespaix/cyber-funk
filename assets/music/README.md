# Musiques

- `*.mp3` à la racine de ce dossier : pistes **libres de droits**, versionnées, listées dans `LICENCES.md`.
- `local/` : vos propres morceaux pour tester (n'importe quel format lu par symphonia : MP3, FLAC, OGG, WAV…).
  Ce dossier est **ignoré par git** : rien de ce qui s'y trouve n'est versionné ni distribué.

Le lecteur de démo charge les deux dossiers. Convention de nom : `Artiste - Titre.ext`.
