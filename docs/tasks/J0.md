# J0 · Fondations

Objectif : un workspace qui compile, deux fenêtres, une CI verte, les assets de base en place.
Démo de fin : fenêtre projecteur + fenêtre opérateur, un cube qui tourne, CI verte sur les trois OS.

Sources Sillage : dépôt `aifedespaix/aifedespaix.com`, chemins relatifs à `apps/main/`.

- **Modèle :** Opus 5.5 · effort `high`
- **Dépend de :** —
- **Crates :** toutes (création)
- **Skills :** `rust-conventions`, `bevy-patterns`, `workflow-conventions`

**À faire**

- `Cargo.toml` racine : workspace, `[workspace.package]`, `[workspace.lints]` et profils tels que décrits dans le skill
  `rust-conventions`, `[workspace.dependencies]` avec les **dernières versions stables** (vérifier avec
  `cargo search` : Bevy, bevy_egui compatible, cpal, symphonia, realfft, rtrb, triple_buffer, midir, serde, ron,
  thiserror, anyhow, tracing, tracing-subscriber, crossbeam-channel, rand_pcg, insta, proptest, criterion).

  `cf-analysis`, `cf-control`, `cf-show`).
- Binaire `cyber-funk` : `main.rs` minimal qui lance une `App` Bevy avec `DefaultPlugins`.
- Feature `dev` sur le binaire (`bevy/dynamic_linking`, `bevy/file_watcher`).

**Critères d'acceptation**

- [ ] `cargo build --workspace`, `cargo clippy --workspace --all-targets -- -D warnings`, `cargo test --workspace` verts.
- [ ] `cargo tree -p cf-show` ne contient pas `bevy`.

- [ ] La CI GitHub (`.github/workflows/ci.yml`) passe sur la PR.

### J0-02 · Fenêtres projecteur et opérateur, journaux, ligne de commande

- **Modèle :** Sonnet 5.5 · effort `high`
- **Dépend de :** J0-01
- **Crates :** `cyber-funk`, `cf-operator`
- **Skills :** `bevy-patterns`, `rust-conventions`

**À faire**

- Fenêtre principale = projecteur : plein écran sans bordure sur l'écran choisi, curseur caché, aucune UI. Fenêtre
  secondaire = opérateur, redimensionnable, avec `bevy_egui` et un panneau vide « cyber-funk ».
- Ligne de commande (`clap`) : `--show <fichier>`, `--projector-monitor <index|nom>`, `--windowed` (projecteur en
  fenêtre pour le dev), `--no-operator`, `--log <niveau>`.
- Journaux `tracing` + `tracing-subscriber` (filtre par `RUST_LOG`), fichier journal tournant dans le dossier de
  données en release.
- Quitter : fermer l'opérateur demande confirmation ; fermer le projecteur aussi. `Échap` ne quitte jamais seul.
- Scène de test : un cube qui tourne sur la caméra du projecteur.

**Critères d'acceptation**

- [ ] Sur Linux (X11 et Wayland si dispo), Windows et macOS : deux fenêtres, le cube s'affiche dans le projecteur seul.
- [ ] `--windowed` et `--projector-monitor` fonctionnent (décrire le test dans la PR).
- [ ] Aucun `println!` (lint), journaux visibles avec `RUST_LOG=info`.
