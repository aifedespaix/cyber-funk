# J7 · Contenu

Objectif : parité visuelle avec Sillage. Gros volume, lots indépendants : à paralléliser.
Crate : `cf-world-neon` (sauf mention). Sources : `apps/main/src/components/sillage/engine/`.

Règle commune : chaque élément expose ses `Subject` au réalisateur, respecte les portes (`events`, `eventRate`,
`stuntKinds`…), marque la fraîcheur, et passe par les pools (aucun spawn en régime établi).
