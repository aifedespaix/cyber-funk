# J8 · Interface opérateur

Objectif : préparer une soirée à plusieurs DJs et la jouer de bout en bout depuis la fenêtre opérateur.
Crate : `cf-operator` (`bevy_egui`). Référence : `docs/ARCHITECTURE.md` §2.5.

Principes UI : lisible dans le noir (contraste fort, grandes cibles), aucun texte plus petit que 14 px en mode Live,
toute action live a un raccourci, rien de destructif sans confirmation en mode Live.

---

- **Modèle :** Sonnet 5.5 · effort `high`
- **Dépend de :** J2-05, J3-06, J4-05
- **Skills :** `bevy-patterns`, `show-model`, `live-safety`
- **Sources :** `SillageOperatorHud.svelte`, `SillageCinemaShow.svelte`, `SillageCinemaKeys.svelte` (informations
  affichées dans Sillage)

**À faire**

- Mise en page de l'architecture §2.5 : frise des créneaux, liste de cues (joué / en cours / suivant, compte à rebours

**Critères d'acceptation**

### J8-07 · Raccord du binaire : assemblage des plugins et du chef du spectacle

- **Modèle :** Sonnet 5.5 · effort `high`
- **Dépend de :** J8-01, J6-02, J4-06, J4-07, J4-02, J4-08
- **Crates :** `cyber-funk` (surtout), `cf-render`, `cf-cinema`, `cf-world-neon` (raccords minimaux)
- **Skills :** `bevy-patterns`, `live-safety`, `render-performance`, `rust-conventions`

Ajoutée par l'orchestrateur : les tâches J3 à J8 ont livré des plugins qui marchent seuls mais que le binaire
n'assemble pas tous. Cette tâche les assemble et vérifie que l'ensemble tient (aucun nouveau système, que du câblage).

**À faire**

- `main.rs` assemble `LayersPlugin`, `PostFxPlugin`, `PalettePlugin`, `QualityPlugin` dans le bon ordre `CfSet`.
- Le réalisateur reçoit le vrai `ShowDirector` (trait `ShowSide`, J6-02) au lieu de `NoShow` : portes de rang, ordres
  `SkipShot`/`ShowDj`, drop préparé et blocage du plan `strobe` selon `flashes` deviennent actifs.
- Le pont du spectacle écrit `CurrentShowFx` à chaque image avec `ShowFxInput::from_show` (J4-02) : sans lui, ni flash
  ni vague (état sûr) ; vérifier que tout passe par le `FlashLimiter`.
- `NeonWorld::set_quality` relié à `QualityChanged` (J4-06) ; `QualityIdle` écrit pendant les chargements ; les
  consommateurs de `QualityLevers` câblés quand ils existent.
- `drop_planned` câblé depuis `cf-world-neon` vers le réalisateur (le plan `dolly-zoom` est sinon indisponible).
- Chemin des assets : relatif au dossier de travail aujourd'hui ; corriger pour que le binaire installé (cargo-packager,
  macOS : `Contents/Resources`) trouve `assets/` (signalé par J9-03 et J4-07).
- Refaire le contrôle de J4-07 « journal de compilation tardive vide » avec tous les plugins assemblés.

**Critères d'acceptation**

- [ ] `cargo run -p cyber-funk -- --show assets/shows/demo.ron` (Xvfb + lavapipe) atteint `Ready` puis tourne 3 min : journal sans `pipeline compilé après Ready`, sans erreur ni avertissement inattendu.
- [ ] Test d'intégration : un set simulé de 10 min avec le vrai `ShowDirector` : coupes sur la grille, plafond de 3 coupes/s tenu, `strobe` jamais choisi quand `flashes` est coupé.
- [ ] Les flashs du post-process et de la voiture ne dépassent pas le plafond du limiteur (test sur la sortie finale).
- [ ] Le binaire trouve ses assets depuis un autre dossier de travail (test ou description du contrôle).
