# J8 · Interface opérateur

Objectif : préparer une soirée à plusieurs DJs et la jouer de bout en bout depuis la fenêtre opérateur.
Crate : `cf-operator` (`bevy_egui`). Référence : `docs/ARCHITECTURE.md` §2.5.

Principes UI : lisible dans le noir (contraste fort, grandes cibles), aucun texte plus petit que 14 px en mode Live,
toute action live a un raccourci, rien de destructif sans confirmation en mode Live.

---

### J8-01 · Vue Live

- **Modèle :** Opus 5.5 · effort `high`
- **Dépend de :** J2-05, J3-06, J4-05
- **Skills :** `bevy-patterns`, `show-model`, `live-safety`
- **Sources :** `SillageOperatorHud.svelte`, `SillageCinemaShow.svelte`, `SillageCinemaKeys.svelte` (informations
  affichées dans Sillage)

**À faire**

- Mise en page de l'architecture §2.5 : frise des créneaux, liste de cues (joué / en cours / suivant, compte à rebours
  d'avancée auto), GO/BACK/HOLD, macros, pads, sécurité (Blackout, Look calme, Flashs), tempo et source, vumètres,
  drop préparé, santé (i/s, GPU, MIDI).
- Mode Live verrouillé (pas d'édition) ; bascule Préparation/Live protégée.

**Critères d'acceptation**

- [ ] Un set de 3 DJs se joue uniquement depuis cette vue (scénario décrit dans la PR, captures).
- [ ] Toutes les actions de la vue ont un raccourci clavier affiché.

---

### J8-02 · Préparation : événement, créneaux, cues

- **Modèle :** Sonnet 5.5 · effort `high`
- **Dépend de :** J8-01, J2-07
- **Skills :** `show-model`, `bevy-patterns`
- **Sources :** `SillageCinemaDjs.svelte`, `SillageCinemaSettings.svelte` (réglages DJ et show de Sillage)

**À faire**

- Édition de l'événement (nom, flashs, latence), des créneaux (identité, logo, thème, horaires, mode, profils), des
  cues (look, entrée, avancée, déclencheurs) : ajout, duplication, glisser-déposer, suppression avec annulation.
- Ouvrir / enregistrer / enregistrer sous, indicateur « modifié ».

**Critères d'acceptation**

- [ ] Annuler/rétablir (Ctrl+Z / Ctrl+Maj+Z) sur toutes les éditions.
- [ ] Le fichier enregistré se recharge à l'identique.

### J8-03 · Éditeur de looks avec aperçu

- **Modèle :** Sonnet 5.5 · effort `high`
- **Dépend de :** J8-02, J4-08
- **Skills :** `show-model`, `render-performance`

**À faire**

- Formulaire des portes, effets, couches, palette, macros ; application en direct sur le projecteur (mode Préparation)
  ; rechargement à chaud quand le fichier RON change sur disque.

**Critères d'acceptation**

- [ ] Modifier un champ change l'image en < 1 s ; une valeur hors plage est refusée avec un message clair.
