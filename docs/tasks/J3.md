# J3 · Contrôles

Objectif : clavier, contrôleurs MIDI et logiciels de mix pilotent le show via une seule couche d'`Action`.
Démo de fin : un contrôleur MIDI fait GO/BACK et tourne les macros ; le tempo suit le MIDI Clock de Traktor ou Rekordbox.

---

### J3-01 · Vocabulaire `Action` et couche de correspondance

- **Modèle :** Opus 5.5 · effort `high`
- **Dépend de :** J0-01
- **Crate :** `cf-control`
- **Skills :** `midi-control`, `rust-conventions`
- **Sources :** `engine/show/operator.ts` (table des touches), `engine/show/types.ts` (`OperatorAction`)

**À faire**

- `enum Action` complet (skill `midi-control`), `InputSource`, `Binding`, modes Momentary/Toggle/Absolute/Relative.
- `Mapper` : reçoit des `RawInput` horodatés, produit des `Action` ; profils RON (`ControlProfile`), fusion de
  plusieurs profils (événement + créneau DJ), détection de conflits.
- Profil clavier par défaut = raccourcis Sillage (lettres par caractère, AZERTY ok ; touches sans lettre par code).
- Ce crate ne dépend ni de Bevy ni de `cf-show`.

**Critères d'acceptation**

- [ ] Tests : chaque raccourci Sillage produit l'action attendue ; conflit de binding signalé au chargement.
- [ ] Profil sérialisé/relu identique.

### J3-02 · Entrée MIDI, profils et MIDI learn

- **Modèle :** Opus 5.5 · effort `high`
- **Dépend de :** J3-01
- **Crate :** `cf-control`
- **Skills :** `midi-control`, `realtime-audio` (règles des callbacks)

**À faire**

- `midir` : ouverture de tous les ports d'entrée (ou d'une sélection), parseur (Note On/Off, CC 7 et 14 bits, CC
  relatifs, Program Change, messages système), canal borné vers le mapper.
- Rebranchement à chaud par nom de port.
- Mode learn : `start_learn(action_template)` → le prochain message devient le binding.
- `examples/midi_monitor.rs`.
- 2 profils d'exemple dans `assets/controllers/` (un contrôleur générique à 8 potards/8 pads, un contrôleur DJ
  courant type Pioneer DDJ-FLX4 si sa table MIDI publique est disponible).

**Critères d'acceptation**

- [ ] Parseur testé octet par octet (dont running status et Note On vélocité 0 = Note Off).
- [ ] Débrancher/rebrancher un contrôleur : reconnecté sans redémarrer (décrire le test).

### J3-03 · MIDI Clock et arbitrage des sources de tempo

- **Modèle :** Opus 5.5 · effort `xhigh`
- **Dépend de :** J3-02, J1-05
- **Crates :** `cf-control` (clock), `cf-analysis` (arbitrage dans `AudioFeatures`)
- **Skills :** `midi-control`, `realtime-audio`

**À faire**

- Décodage clock 24 ppqn avec filtre anti-gigue, Start/Continue/Stop/SPP, phase dans la mesure.
- Tap tempo (`Action::TapTempo`), `Resync`, `NudgePhase`.
- Arbitrage Clock/Link > Audio > Tap, bascule sans saut de phase, repli après 2 s de perte, publication de
  `tempo_source` et `confidence`.

**Critères d'acceptation**

- [ ] Tests synthétiques : gigue ±2 ms → BPM stable à ±0,1 ; changement de tempo suivi en < 2 mesures ; perte → repli.
- [ ] Test réel avec un logiciel de mix (Traktor, Rekordbox ou Mixxx) décrit dans la PR.

### J3-06 · Pont Bevy des contrôles

- **Modèle :** Sonnet 5.5 · effort `medium`
- **Dépend de :** J3-01, J2-05, J0-02
- **Crates :** `cf-render` (plugin d'entrée) ou `cyber-funk`
- **Skills :** `bevy-patterns`, `midi-control`

**À faire**

- Clavier Bevy (fenêtres projecteur **et** opérateur, sauf quand un champ texte egui a le focus) → `RawInput`.
- Threads MIDI/OSC démarrés par le plugin ; `Action` publiées en messages Bevy en `CfSet::Input`, puis passées au
  `ShowDirector` en `CfSet::Show` (plugin `ShowPlugin` qui publie `Res<ShowState>`).
- Panneau opérateur minimal : ports MIDI vus, dernier message, dernière action, source de tempo.

**Critères d'acceptation**

- [ ] Appuyer sur → au clavier ou sur un pad MIDI change le cue (visible dans le panneau).
- [ ] Taper du texte dans egui ne déclenche aucune action.
